MathQuiz

Prosta gra mobilna w formie quizu matematycznego napisana w Java w Android studio

FUNKCJE
- Trzy poziomy trudności (ławtey, średni, trudny)
- Losowe działania z limitem czasu
- 10 pytań w rundzie
- Podsumowanie po każdej rozegranej rundzie (punkty, seria poprawnych odpowiedzi)
- Zapisany najlepszy wynik

TECHNOLOGIE
- Android studio
- java
- Android SDK

STRUKTURA
- MainActivity – wybór poziomu, start gry
- QuizActivity – logika, timer, punktacja
- ResultActivity – wynik końcowy i rekord
- Question – model pytania
- QuestionGenerator – generowanie pytań
